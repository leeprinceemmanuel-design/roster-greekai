# Roster (GreekAI)

Starter for Roster, an AI-assisted recruitment platform. PDC50 group project.

Members: Agustin, John Micheal; Busa, Jerry Jr; Lee, Prince Emmanuel

## Run it

```bash
npm install
npm run dev
```

- Web page: http://localhost:5173
- API health check: http://localhost:3000/health

## Team rules

- Never commit directly to `main`.
- Branch names: `feature/short-description`
- All changes go through a pull request.
